# 注意力 · Attention Is All You Need

「量子力学」「量子隧穿」之后的第三部。这一部讲的是 2017 年那篇改变了 AI 的论文。

- **规格：** 3 分 58 秒，竖屏 9:16（1080×1920）/ 30 fps，直接按抖音信息流的画幅制作。
- **声音：** 没有配音，讲述全部交给中英双语字幕；配乐为原创，由代码合成。

- **成片（便于传输的版本）：** [`attention.mp4`](attention.mp4)
- **高清母版：** [`attention-master.mp4`](attention-master.mp4)，即渲染原始码流，通过 Git LFS 存放
- **封面：** [`cover-9x16.png`](cover-9x16.png)（视频封面）/ [`poster-3x4.png`](poster-3x4.png)（主页网格）
- **发布文案与章节：** [`douyin.md`](douyin.md)

## 主线

开头不先讲概念，而是让观众自己做一次「注意力」：

1. 看到「小猫没有跳上桌子，因为它太累了」，你一眼就知道「它」是小猫。
2. 把「累」换成「高」，「它」又变成了桌子。
3. 这时才点破：你刚才做的这件事，就叫「注意力」。

后面每一章，都在讲机器怎么学会这件事。

| 时间 | 章节 | 画面 |
|------|------|------|
| 00:00 | 它是谁 | 星座连成的小猫和桌子跟着句子演出来：小猫跳不上去，趴下休息；「累」换成「高」，桌子长高。「它」看向谁，谁就亮成金色 |
| 00:24 | 逐字 | 四个人的侧影排成一排传话，消息每传一次就暗一点、糊一点；下面的句子一个字一个字地读，读到「它」时，「小猫」已经很淡了 |
| 00:58 | 一眼 | 所有字同时出现，彼此连成网；随后出现注意力表，所有格子在同一瞬间亮起（数值为示意） |
| 01:30 | 问与答 | 一位读者举着问题卡片（Q），书架上每本书有书脊标签（K）和内容（V）；问题和标签越对得上，光束越亮，最后揭晓公式 softmax(QKᵀ/√dₖ)V |
| 02:12 | 八双眼睛 | 同一句话上依次出现八种颜色的连线，分别对应指代、动作、主语、原因、左邻、右邻、否定、全局，最后合在一起 |
| 02:38 | 顺序 | 星座的猫和狗互相追逐，「猫追狗」三个字换位成「狗追猫」；每个位置被印上四条快慢不同的波，像指纹一样 |
| 03:04 | 之后 | 论文首页与「Equal contribution. Listing order is random.」，披头士的唱片，GPT 里的「T」，一层层叠起来的 Transformer |

## 史实

- **论文：** Vaswani、Shazeer、Parmar、Uszkoreit、Jones、Gomez、Kaiser、Polosukhin 合著，2017 年 6 月发表于 arXiv（1706.03762），同年发表于 NIPS。
- **作者排序：** 署名脚注写着 "Equal contribution. Listing order is random."
- **模型结构：** base 模型使用 8 个注意力头，位置编码是不同频率的正弦和余弦。
- **GPT：** 全称 Generative Pre-trained Transformer。

## 配乐

原创，全部由 `music.py` 用代码合成（依赖 `synth.py`）。声音都跟着画面里讲的内容走：

- **逐字读：** 每读一个字，响一声轻轻的嘀嗒。
- **传话：** 每传一次，悄悄话的声音就更轻一点。
- **注意力表：** 所有格子亮起的那一刻，所有声音同时响起。
- **八双眼睛：** 每双眼睛对应一个音，依次升高。
- **位置编码：** 四条波，对应四个纯音。
- **响度：** −14.6 LUFS。
