## 主线

目标是看完的人能说出 Transformer **到底是怎么算的**，再往前想一步：为什么"猜下一个字"会像智能。

贯穿全片的比喻：**每个字，都是「意义星空」里的一颗星**。注意力做的事，就是让每颗星看看身边的星，再挪到它该在的位置。

## 史实

- **论文：** Vaswani、Shazeer、Parmar、Uszkoreit、Jones、Gomez、Kaiser、Polosukhin 合著，2017 年 6 月发表于 arXiv（1706.03762），同年发表于 NIPS。署名脚注写着 "Equal contribution. Listing order is random."
- **模型：** base 模型每个字 512 个数、6 层、8 个注意力头、每个头 64 维（所以除以 √64＝8）；大模型在 8 块 P100 显卡上训练 3.5 天，WMT 2014 英译德 28.4 BLEU（比此前最好结果高 2 分以上），英译法 41.8 BLEU。
- **GPT-3：** 1750 亿参数、96 层、每个字 12288 个数，训练数据约 3000 亿个词元。
- **词向量：** 「国王 − 男人 + 女人 ≈ 女王」出自 2013 年的 word2vec 研究。
- **其他：** 椋鸟群中每只鸟大约只跟随身边 6～7 只（Ballerini 等，2008）；人脑约有 860 亿个神经元（Azevedo 等，2009）。
- 片中的概率、坐标和注意力数值都是讲解用的示意数字，画面上标有"示意"。

## 配乐

原创，全部由 `music.py` 用代码合成（依赖 `synth.py`）：柔和的铺底、钢琴、玻璃钟声、拨弦，讲解密集处加入轻快的律动（底鼓、踩镲、贝斯），每个揭晓的瞬间都有重音。

- **逐字读：** 每读一个字，响一声轻轻的嘀嗒。
- **算式：** 算式每写出一项，响一个音；「它」落到小猫身边时，音乐落下。
- **注意力表：** 所有圆点弹出的那一刻，所有声音同时响起。
- **涌现：** 椋鸟群下是一片细碎的嘀嗒声。
- **响度：** −14.6 LUFS。
