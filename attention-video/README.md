# 注意力 · Attention Is All You Need

「量子力学」「量子隧穿」之后的第三部。这一部讲的是 2017 年那篇改变了 AI 的论文。

- **规格：** 3 分 58 秒，竖屏 9:16（1080×1920）/ 30 fps，直接按抖音信息流的画幅制作。
- **声音：** 没有配音，讲述全部交给中英双语字幕；配乐为原创，由代码合成。

- **成片（便于传输的版本）：** [`attention.mp4`](attention.mp4)
- **高清母版：** [`attention-master.mp4`](attention-master.mp4)，即渲染原始码流，通过 Git LFS 存放
- **封面：** [`cover-9x16.png`](cover-9x16.png)（视频封面）/ [`poster-3x4.png`](poster-3x4.png)（主页网格）
- **发布文案与章节：** [`douyin.md`](douyin.md)

## 主线

开头不先讲概念，而是让观众自己做一次「注意力」：

1. 看到「小猫没有跳上桌子，因为它太累了」，你一眼就知道「它」是小猫。
2. 把「累」换成「高」，「它」又变成了桌子。
3. 这时才点破：你刚才做的这件事，就叫「注意力」。

后面每一章，都在讲机器怎么学会这件事。

| 时间 | 章节 | 画面 |
|------|------|------|
| 00:00 | 它是谁 | 一幅星图式的插画：小猫按旧星图的画法，先亮星、再连线、最后浮出雕版式的轮廓，旁边是一张明式桌子的立面。小猫跳不上去，趴下睡了；「累」换成「高」，桌子长高，金线从「它」改连到「桌子」 |
| 00:24 | 逐字 | 四个剪影侧像排成一排传话（18 世纪剪纸肖像的样式，背后透着暖光），消息每传一次就暗一点、糊一点；下面的句子一个字一个字地读，读到「它」时，「小猫」已经很淡了 |
| 00:58 | 一眼 | 左右两列同样的字，每个字同时连向所有的字。这是论文作者之一 Llion Jones 做的 Tensor2Tensor 可视化画法；随后换成注意力表，圆点越大，注意力越强，所有圆点在同一瞬间弹出（数值为示意） |
| 01:30 | 问与答 | 「它」举着问题卡片（Q：我指谁？），其余每个字带着一张标签（K）和一份内容（V）；问题和标签越对得上，连线越亮，内容就越多地流向「它」；最后揭晓公式 softmax(QKᵀ/√dₖ)V |
| 02:12 | 八双眼睛 | 同样的两列字，顶部一排八个彩色方块，对应八个注意力头，依次亮起：指代、动作、主语、原因、左邻、右邻、否定、全局；最后合成金色 |
| 02:38 | 顺序 | 「猫追狗」三个大字换位成「狗追猫」；每个位置被印上四条快慢不同的波，像指纹一样 |
| 03:04 | 之后 | 按原样排版的论文首页，脚注「Equal contribution. Listing order is random.」被划亮；转动的黑胶唱片《All You Need Is Love》；GPT 里的「T」；按论文图 1 画的 Transformer 层，一层层叠起来（N×） |
| 03:34 | 你的注意力 | 银河下，一个剪影仰头看星，星星彼此连成星座；「注意力，也许真的就是你所需要的一切。」 |

画面只在需要时出现，并且都参照了经典设计：动物和桌子用旧星图（Hevelius《Firmamentum》、Urania's Mirror）的画法，人物用剪纸剪影（Lotte Reiniger、18 世纪侧影肖像），讲解部分用论文作者自己的可视化和 3Blue1Brown 的注意力网格。全片没有章节标记。

## 史实

- **论文：** Vaswani、Shazeer、Parmar、Uszkoreit、Jones、Gomez、Kaiser、Polosukhin 合著，2017 年 6 月发表于 arXiv（1706.03762），同年发表于 NIPS。
- **作者排序：** 署名脚注写着 "Equal contribution. Listing order is random."
- **模型结构：** base 模型使用 8 个注意力头，位置编码是不同频率的正弦和余弦。
- **GPT：** 全称 Generative Pre-trained Transformer。

## 配乐

原创，全部由 `music.py` 用代码合成（依赖 `synth.py`）。声音都跟着画面里讲的内容走：

- **逐字读：** 每读一个字，响一声轻轻的嘀嗒。
- **传话：** 每传一次，悄悄话的声音就更轻一点。
- **注意力表：** 所有格子亮起的那一刻，所有声音同时响起。
- **八双眼睛：** 每双眼睛对应一个音，依次升高。
- **位置编码：** 四条波，对应四个纯音。
- **响度：** −14.6 LUFS。
