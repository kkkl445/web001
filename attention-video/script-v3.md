# 注意力 · 第三版脚本（待确认）

目标：看完的人能说出 Transformer **到底是怎么算的**，而不只是"看过了"。
全片约 6 分钟，竖屏 9:16，依旧只用字幕讲述。

贯穿全片的一个比喻：**每个字，都是「意义星空」里的一颗星。**
注意力做的事，就是让每颗星看看身边的星，然后挪到它该在的位置。
星空的画法沿用上一版已确认的星图风格，所以这个比喻在画面上是现成的。

---

## 0　开场：猜下一个字（0:00–0:35）

| 字幕 | 画面 |
|---|---|
| 先来玩个游戏：下一个字是什么？ | 一行字逐字打出「小猫没有跳上桌子，因为它太＿」，光标闪烁 |
| 你大概会猜「累」，或者「高」。 | 候选字浮出，变成一排金色的概率条：累 41%、高 23%、小 9%、胖 6%……（标注"示意"） |
| ChatGPT 做的事，说穿了就是这个游戏：猜下一个字。 | 一段聊天回答逐字生成，每个字出现前，上方都闪过一排候选条 |
| 猜一个，接上，再猜下一个——一整段回答，就是这样写出来的。 | 同上，加速 |
| 可要猜得准，它得先弄明白：这里的「它」，到底是谁？ | 切回星图：小猫和明式桌子，金线从「它」连向小猫；「累」换成「高」，金线改连桌子 |
| 你一眼就知道。而让机器也学会这件事的，是 2017 年的一篇论文。 | 标题：Attention Is All You Need |

## 1　字是星星：意义的星空（0:35–1:25）

| 字幕 | 画面 |
|---|---|
| 机器不认识字，只认识数字。 | 「猫」字展开成一长列数字：0.21、−1.30、0.84…… |
| 所以第一步，把每个字变成一串数字：论文里是 512 个，GPT-3 里是 12288 个。 | 数字列继续往下延伸，数到底 |
| 把这串数字想成一个位置——每个字，都是「意义星空」里的一颗星。 | 数字收拢成一颗星，飞进星空 |
| 意思相近的字，挨得也近。 | 星空展开：猫、狗、老虎聚成一团；桌子、椅子、床一团；累、困、饿一团 |
| 连方向都有意思：从「男人」到「女人」，和从「国王」到「女王」，几乎是同一步。 | 两支平行的金色箭头 |
| 可同一个字，在不同的句子里，意思并不一样。 | — |
| 「我吃了一个苹果」和「苹果发布了新手机」，是两个苹果。 | 「苹果」这颗星，一会儿被拉向水果，一会儿被拉向手机 |
| 而「它」自己几乎没有意思，孤零零地悬在中间。 | 星空正中，一颗暗淡的星：它 |
| 注意力要做的，就是让每个字看看身边的字，再把自己挪到该去的地方。 | 「它」被一根金线拉向「小猫」 |

## 2　以前的办法：传话（1:25–1:55）

| 字幕 | 画面 |
|---|---|
| 在很长一段时间里，机器读句子，主要靠一个字一个字地读。 | 剪影传话（上一版画面） |
| 每读一个字，就把记住的东西，传给下一个字。 | 消息逐个传递 |
| 就像传话游戏：传得越远，开头就越模糊。 | 消息越传越暗、越糊 |
| 而且只能排队，没法同时进行——句子越长，越慢，也越健忘。 | 句子逐字点亮，开头淡去 |

## 3　注意力是怎么算的（1:55–3:35）——全片核心

| 字幕 | 画面 |
|---|---|
| 这篇论文换了个思路：不排队，让每个字直接看向所有的字。 | 两列字，全部互连 |
| 可它怎么知道，该看谁？ | 只留「它」 |
| 每个字，用自己的那串数字，分别乘上三张「表」，得到三样东西： | 字的数字列 × 三张表 → 三列新数字，标 Q、K、V |
| Q，问题：我在找什么？ | — |
| K，标签：我是什么？ | — |
| V，内容：要是你选中我，我给你什么。 | — |
| 比如「它」的问题，大概是："前面哪个东西会累？" | 一张小坐标图：横轴"会累的（活物）"，纵轴"是个物件"；金色箭头 Q＝(2, 0) |
| 每个字也亮出自己的标签。问题和标签，比一比有多对得上。 | 小猫 K＝(1.5, 0.5)、桌子 K＝(0, 2)、累 K＝(1, 0) |
| 怎么比？两串数字对应相乘，再加起来。 | 算式逐项写出：2×1.5 ＋ 0×0.5 ＝ 3 |
| 两支箭头方向越一致，得分越高。 | 小猫的箭头和 Q 几乎同向；桌子的箭头和 Q 垂直，得 0 分 |
| 小猫 3 分，累 2 分，跳上 1 分，桌子 0 分…… | 一列分数 |
| 再把分数变成百分比，加起来正好 100%。这一步叫 softmax：分数越高，分到的越多。 | 分数变成概率条：小猫 57%、累 21%、跳上 8%，其余各 3% |
| 最后按这个比例，把每个字的内容 V 混在一起，交给「它」。 | 各字的 V 按比例流向「它」 |
| 于是，「它」那串数字里，一大半来自小猫。 | 回到星空：「它」这颗星被拉到小猫身边 |
| 「它」终于知道，自己是谁了。 | — |
| 刚才这几步，写成一行，就是整篇论文的核心。 | 公式 Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V 出现 |
| QKᵀ 是"比一比"，softmax 是"变成百分比"，乘 V 是"按比例取内容"。 | 公式各部分依次点亮，下面标注刚才的中文 |
| √dₖ 呢？论文里每支箭头有 64 个数，除以 8，免得分数大得失控。 | √dₖ 点亮 |
| 而且，所有字是同时这样算的：一整张表，一次算完。 | 注意力网格，圆点同时弹出 |
| 这正是显卡最擅长的事——所以它算得快，也能做得很大。 | — |

## 4　八双眼睛（3:35–4:00）

| 字幕 | 画面 |
|---|---|
| 一组 Q、K、V，只能看出一种关系。那就同时用八组。 | 八个彩色方块 |
| 有的找「它」指谁，有的找谁做了什么，有的只看身边的字。 | 八种颜色的连线依次出现 |
| 这叫「多头注意力」。最后，把八种看法拼在一起。 | 合成金色 |

## 5　顺序（4:00–4:20）

| 字幕 | 画面 |
|---|---|
| 同时看所有的字，会把顺序丢掉：「猫追狗」和「狗追猫」，是同样三个字。 | 猫追狗 → 狗追猫 |
| 所以每个位置，都被加上一组快慢不同的波，像指纹。顺序，就藏进了数字里。 | 四条波 |

## 6　叠起来，学出来（4:20–5:05）

| 字幕 | 画面 |
|---|---|
| 一次注意力，加一步简单的计算，叫做一「层」。 | 论文图 1 的一层 |
| 论文叠了 6 层；GPT-3 叠了 96 层。 | 层一张张叠起来 |
| 每过一层，每颗星都再挪一挪，意思就更准一点。 | 星空里，「它」一步步移动 |
| 可那三张「表」里的数字，是谁填的？ | — |
| 没有人填。给它海量的文字，遮住下一个字，让它猜。 | 一句话的最后一个字被遮住 |
| 猜错了，就把所有数字往"猜对"的方向，轻轻拧一点。 | 无数刻度同时微调 |
| 重复几千亿次。GPT-3 一共有 1750 亿个这样的数字。 | 数字滚动：175,000,000,000 |
| 当年，论文里的模型只用 8 块显卡训练了 3.5 天，就在英译德上超过了此前所有的方法。 | 论文首页 |
