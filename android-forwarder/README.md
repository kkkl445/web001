# 微信内网转发（Android）

把**白名单联系人**的微信消息，自动转发到公司 **G平台（云之家二次开发）** 的**文件传输助手**，这样在只有内网的办公室里也能第一时间看到重要微信。

## 工作原理

整个流程都在你自己的手机上完成，不需要服务器，也不需要破解 G平台 的接口：

```
微信来消息
   │  ① 通知监听服务读取通知（发件人 + 内容）
   ▼
判断发件人是否在白名单
   │  命中
   ▼
拼成一句话：【微信】张三：晚上开会
   │  ② 无障碍服务「模拟手指」操作 G平台
   ▼
自动打开 G平台 → 文件传输助手 → 输入 → 点发送
   ▼
你在 PC 端的 G平台 就能看到
```

- **①通知监听**：`WeChatNotificationListener`，读取微信通知栏消息。
- **②无障碍自动化**：`ForwarderAccessibilityService`，自动操作 G平台 界面完成发送。

这种方式的好处：**不依赖 G平台 的登录令牌和请求签名，App 更新一般也不会失效。**

## 怎么编译成 APK

需要一台电脑（Windows/Mac 都行）：

1. 安装 **Android Studio**（官网 https://developer.android.com/studio ，免费）。
2. 打开 Android Studio → `File → Open`，选择本项目的 `android-forwarder` 文件夹。
3. 首次打开会自动联网下载 Gradle 和依赖（耐心等几分钟，右下角有进度）。
4. 等左下角 `Sync` 完成、没有红色报错后，点顶部菜单 `Build → Build Bundle(s) / APK(s) → Build APK(s)`。
5. 构建完成后右下角弹窗点 `locate`，找到 `app/build/outputs/apk/debug/app-debug.apk`。
6. 把这个 `app-debug.apk` 传到手机安装（需要允许「安装未知来源应用」）。

> 如果 `Sync` 报缺少 SDK，按 Android Studio 的提示点 `Install` 自动补齐即可。

## 手机上怎么用（第一次配置）

打开 App，按界面上的序号一步步来：

1. **① 开启微信通知读取权限**：跳到系统设置，找到「微信内网转发」，打开通知使用权。
2. **② 开启无障碍权限**：在无障碍列表里找到「G平台自动发送服务」，打开。
   - vivo/小米等国产系统可能还需要在「权限管理」里给本 App 允许**后台弹出界面 / 自启动**，否则自动打开 G平台 会被拦。
3. **③ 白名单联系人管理**：把你关心的联系人名字（微信里显示的备注名）加进去。
4. **④ 参数设置**：一般用默认即可。目标 App 包名默认为 `com.yunzhijia.gree`，如果不对，见下方「调试」。
5. 回到主页，打开最上面的**转发总开关**。
6. **重要**：把 G平台 打开一次，停在**文件传输助手**的聊天界面（或让它在会话列表顶部，方便自动点开）。

配置完，可以先点主页的「发一条测试消息试试」，再去「运行日志」看它有没有成功发进 G平台。

## 调试（第一次多半需要）

无障碍自动化是「对着 G平台 界面点」的，你的界面按钮位置/文字我这边看不到，所以**第一次很可能发送失败**，这很正常。排查方法：

1. 点「发一条测试消息」，然后打开「运行日志」。
2. 如果失败，日志里会自动打印**当前界面结构**，例如：
   ```
   ---- 当前界面结构（发我这段即可调参）----
   FrameLayout
     EditText #chat_input "" [E]
     Button #btn_send "发送" [C]
   ...
   ```
3. 把这段日志（点右上「复制」）发出来，就能对照调整：
   - **目标 App 包名不对** → 日志会显示实际包名，去「参数设置」改。
   - **发送按钮文字不是「发送」** → 去「参数设置」的「发送按钮文字」里补上日志里那个按钮的文字。
   - **会话名不是「文件传输助手」** → 去「参数设置」改成实际名字。

## 已知限制

- 微信如果把通知折叠成「你有 N 条新消息」，读不到具体内容——需要在微信里把消息通知设为**显示详情**。
- 手机正在前台用微信时不会有通知，此时不会转发（对「人在工位、手机在兜里」的场景没影响）。
- 转发瞬间会短暂跳到 G平台 界面（模拟操作的代价）。
- 仅用于把**你自己**收到的消息转发给**你自己**，请勿用于其他用途。
