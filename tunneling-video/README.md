# 量子隧穿 · Quantum Tunneling

《量子力学》的姊妹篇，只讲一个小概念：**电子为什么能穿过一堵本该穿不过的墙。**
2 分 46 秒，1080p / 30 fps。没有配音：画面中央一次只出现一句话，底部的中英双语字幕负责讲述，配乐为原创。

**成片：[`quantum-tunneling.mp4`](quantum-tunneling.mp4)**

## 风格

参考「Vibe 知识大赏」那种电影感，而不是幻灯片：

- 近乎全黑的星空底色，压暗的四角，细腻的胶片颗粒，所有发光的东西都带辉光
- 画面中央只放一个元素：一句逐字打出的宋体大字、一个金色填空（候选词像老虎机一样滚动），或者一件发光的"仪器"（概率刻度、数轴）
- 底部是中英双语字幕，英文为意大利体
- 左上角只有一个极小的章节标记，例如 `01 墙 THE WALL`
- 金色代表"穿过 / 可能"，冰蓝色代表"被弹回 / 波"；离场的文字会模糊、上飘、消散

## 结构

| 章节 | 画面 | 背后的物理 |
|------|------|-----------|
| 00 序 | 「球撞向墙，弹了回来。」概率刻度停在 0。换成电子：「它会＿＿」，填空在"弹回"和"穿过"之间不停滚动 | 一次反射，一次穿透 |
| 01 墙 | 一条金色的山丘曲线，小球滚上去又滚回来，比它能量高的区域被标成暗红色的"禁区"，最后浮现「不可能」 | 能量守恒积分出小球的运动 |
| 02 波 | 小球化作一团发光的波包，金色光点按概率在波里随机闪现 | \|ψ\|² 采样 |
| 03 穿 | 一团波撞上发光的玻璃墙，墙前激起干涉涟漪，另一侧亮起一团金色的光，最终 80% 弹回、20% 穿过 | 二维含时薛定谔方程的分步傅里叶数值解 |
| 04 薄 | 金色数轴上的标记随墙厚移动，概率读数里的 0 越来越多：0.024 → 0.00014 → … → 0.000000005，最后浮现 T ≈ e^(−2κa) | 1 eV 电子、2 eV 势垒的精确透射率 |
| 05 光 | 太阳、扫描隧道显微镜看到的原子阵列、手机芯片 | 隧穿在现实中的三个应用 |
| 06 终 | 满屏闪烁的微光，「不可能」碎成金色粒子，再重组成「概率很小」 | |

## BGM

原创，全部由 `music.py` 用代码合成，不使用任何采样。

- 底层是暗色的环境音乐：温暖的合成器铺底、低音持续音、稀疏的毛毡钢琴、FM 玻璃钟声
- 音效与画面逐一对齐：
  - 填空滚动时有细碎的滴答声
  - 球和电子撞墙时有撞击声
  - 片名出现前有一段上扬音，片名落下时一记重音
  - 光点闪现时有清脆的叮声
  - 波撞墙时有低沉的轰鸣，穿过去时有一串钟声
  - 第 4 部分墙每加厚一次，就响起一声音调更低的脉冲
  - 太阳和满屏微光出现时音乐随之涌起
  - 「不可能」碎成粒子前有上扬音，重组成「概率很小」时落在一个解决的和弦上
- 响度 −14.5 LUFS
