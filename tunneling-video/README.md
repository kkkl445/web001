# 量子隧穿 · 南墙之外

《量子力学》的姊妹篇。2 分 58 秒，1080p / 30 fps，没有配音：画面中央一次只出现一句话，底部的中英双语字幕负责讲述，配乐为原创。

**成片：[`quantum-tunneling.mp4`](quantum-tunneling.mp4)**

## 主线

全片只讲一件事：**我们以为的「不可能」，其实只是「概率很小」；而我们，恰恰活在这个极小的概率里。**
每个画面手段都在演示这件事本身，不做装饰。

| 章节 | 观众经历什么 | 物理 |
|------|--------------|------|
| 00 序 | 「不撞南墙不＿」，你脑中自动补上"回头"，"回头的概率"刻度停在 100%。换成电子撞墙，五次里有一次没有回头，刻度变成 < 100%。片名「量子隧穿 · 南墙之外」 | |
| 01 墙 | 金色山丘曲线上，小球爬到半山腰又滚回来；比它能量高的区域是"禁区"，最后浮现「不可能」 | 由能量守恒积分出的运动 |
| 02 波 | 电子化作一团"可能"，金色光点按概率随机闪现 | \|ψ\|² 采样 |
| 03 渗 | 波渗进发光的玻璃墙。墙被切成 0.1 纳米厚的薄片，光每穿过一层就暗一截，读数从 1 一路掉到 0.000000005。T ≈ e^(−2κa) 出现后，「不可能」碎成粒子，重组为「概率很小」 | 二维含时薛定谔方程的数值解；1 eV 电子、2 eV 势垒的精确透射率（越往深处，每层约只放过 36%） |
| 04 零 | 一个人穿墙的概率：小数点后的 0 铺满屏幕、停不下来 | |
| 05 光 | 「太阳，就是黑的。」静默之后太阳点燃：中心约 1500 万度，按经典物理不够聚变，靠隧穿才能发生；但聚变极其罕见，一个质子平均要等几十亿年，所以太阳能稳定燃烧 46 亿年，久到足以孕育生命 | |
| 06 终 | 回到「不撞南墙不＿」，空格留给你：这一次，答案不止一个 | |

## 风格

- 近乎全黑的星空，压暗的四角，胶片颗粒，所有发光物都带辉光
- 宋体大字逐字打出，离场时模糊、上飘、消散；底部是中英双语字幕
- 左上角只有极小的章节标记
- 金色代表"穿过 / 可能"，冰蓝色代表"回头 / 波"

## 配乐

原创，全部由 `music.py` 用代码合成。底层是暗色的环境音乐（合成器铺底、低音持续音、毛毡钢琴、玻璃钟声），音效跟着叙事走：

- 填空出现时几乎没有声音，留给你自己补全
- 电子被弹回时是一声玻璃般的轻响，穿过去的那一个是一串上扬的钟声
- 墙每多一层就响一下，一层比一层低、一层比一层弱
- 0 越涌越快时，嗡鸣声越来越响
- 「太阳，就是黑的。」之前几乎是一片寂静，太阳点燃时声音轰然涌起
- 最后安静地回到那个空格
- 响度 −14.6 LUFS

