# 量子隧穿 · 南墙之外

《量子力学》的姊妹篇。4 分 19 秒，1920×864（2.22 : 1 宽银幕）/ 30 fps，没有配音。画面中央一次只出现一句话，讲述交给底部的中英双语字幕，配乐为原创。

**成片：[`quantum-tunneling.mp4`](quantum-tunneling.mp4)**　·　封面：[`poster-3x4.png`](poster-3x4.png)（竖版 3:4）/ [`cover-16x9.png`](cover-16x9.png)（横版 16:9）

封面的主图就是片中的二维模拟本身：波撞墙之后，蓝色的八成回头，金色的两成穿了过去。

## 主线

全片讲两件事：

1. 我们以为的「不可能」，其实只是「概率很小」。
2. 概率很小的事，只要试得足够多次，就会发生。铀会衰变，太阳会发光，手机能存下照片，都是这样来的。

## 形式即内容

每一章的画面手段本身就是这一章的知识点，不做装饰。

| 章节 | 画面手段 | 它在演示什么 |
|------|----------|--------------|
| 00 序 | 「不撞南墙不＿」：你脑中自动补上"回头"，刻度停在 100%。换成电子，五次里有一次穿了过去 | 经典世界的确定性，以及它的第一道裂缝 |
| 01 墙 | 小球在能量山丘上爬到一半又滚回来，越不过的区域标成"禁区"，最后浮现「不可能」 | 能量守恒积分出的真实运动 |
| 02 渗 | 电子化作一团"可能"，金色光点按概率闪现；这团波撞上玻璃墙，八成弹回，两成穿出 | 二维含时薛定谔方程的数值解，读数 80% / 20% 取自模拟结果 |
| 03 层 | 墙切成 0.1 纳米的薄片，光每过一层就暗一截。小数点后的 0 越来越多，"回头的概率"刻度停在 99.9999995%，肉眼已和 100% 分不出来。随后「不可能」碎成粒子，重组为「概率很小」；一个人穿墙的概率，0 写满屏幕也停不下来 | 指数衰减（1 eV 电子、2 eV 势垒的精确透射率） |
| 04 狱 | 先在黑暗里听见盖革计数器的咔嗒声，再回到 1928 年：伽莫夫画出"火山口"状的原子核，α 粒子在里面来回撞墙。计数器从 1 数到 1.4×10³⁸，经过时间从"不到 1 秒"走到 45 亿年，"仍被困住的概率"在最后一刻落到 50%，它才沿着金色隧道穿出去 | 极小概率 × 极多次尝试 = 半衰期。撞击声一开始还能一下下数清，越撞越快，最后连成一个音高 |
| 05 光 | 爱丁顿 1926 年"去找个更热的地方"；1929 年答案揭晓。镜头从几十个互相弹开的质子一路拉远到 10⁵⁷ 个，每一次聚变是一个金色火花，火花越来越密，最终汇成太阳。随后镜头再退一步，原来这一切都在你手机的屏幕上：闪存里，电子正一个个穿过几纳米厚的墙 | 罕见事件累积成稳定的光；隧穿就在你手里 |
| 06 终 | 长城沿着山脊延伸，太阳从墙后升起："宇宙里，没有绝对的南墙。"回到「不撞南墙不＿」：刻度上写着 < 100%，空格留给你 | |

贯穿全片的仪表是"回头的概率"刻度，读数依次为 100% → < 100% → 80% → 99.9999995% → < 100%。

颜色语义也全片统一：冰蓝 = 回头 / 墙，金色 = 穿过 / 可能。

## 史实与数字

- 伽莫夫 1928 年用隧穿解释 α 衰变（同年还有格尼与康登），当年他 24 岁。
- 铀-238：α 粒子每秒撞墙约 10²¹ 次，半衰期 44.7 亿年，约等于地球年龄。由此每次撞墙穿过的概率约为 10⁻³⁸。
- 爱丁顿的原话出自《恒星内部结构》（1926）："We do not argue with the critic who urges that the stars are not hot enough for this process; we tell him to go and find a hotter place."
- 阿特金森与豪特曼斯在 1929 年把隧穿用到恒星上。太阳每秒约有 3.6×10³⁸ 个质子参与聚变，太阳里共有约 10⁵⁷ 个质子。
- NAND 闪存靠 Fowler–Nordheim 隧穿，把电子穿过几纳米厚的氧化层写入存储层。

## 配乐

原创，全部由 `music.py` 用代码合成。底层是暗色的环境音乐（合成器铺底、低音持续音、毛毡钢琴、玻璃钟声），音效与画面同帧，所有随机事件都用 `timeline.py` 里的固定种子生成：

- 盖革计数器的咔嗒声就是 α 衰变本身：先在近乎无声中响起，章末再和音乐一起出现。
- α 粒子每撞一次墙响一声。越撞越快之后，变成一串越来越密的脉冲，最后连成一个音高；声音戛然而止的那一刻，它穿了过去。
- 太阳里第一次聚变是一声清亮的钟声，之后的火花越来越密，汇成一片沙沙的光，最后在太阳成形时轰然展开。
- 薄片每多一层就响一下，一层比一层低、一层比一层弱。
- 响度 −14.6 LUFS。
