# 量子隧穿 · Quantum Tunneling

《量子力学》的姊妹篇，只讲一个小概念：**电子为什么能穿过一堵本该穿不过的墙。**
2 分 04 秒，1080p / 30 fps，没有配音，靠画面上的文字讲解，配乐为原创。

**成片：[`quantum-tunneling.mp4`](quantum-tunneling.mp4)**

## 风格

和上一部的深色宇宙风相反，这一部用浅色的瑞士杂志版式：

- 暖色纸张底纹、裁切标记、页眉页脚和时间码，像一本印刷的科学杂志
- 粗黑思源宋体（Noto Serif SC 900）做大标题，思源黑体做正文，IBM Plex Mono 做图注标签，Inter Tight 显示数字
- 只用墨黑和朱红两种颜色；势垒用斜线排线填充，概率用网点填充
- 文字从基线下方逐行升起；章节之间用朱红色整屏划过来转场

## 结构

| 部分 | 内容 | 画面背后的物理 |
|------|------|----------------|
| 开场 | 220 个电子射向一堵墙，约五分之一穿了过去 | 按 19% 的透射概率随机抽样 |
| 01 经典的墙 | 小球能量不够，滚上山坡又滚回来；山顶附近是"禁区" | 能量守恒积分出小球的运动 |
| 02 电子是一团波 | 小球化作波包，山坡理想化成一堵薄墙 | 高斯波包 |
| 03 渗进墙里 | 波包撞墙，81% 反射，19% 穿过 | 含时薛定谔方程的分步傅里叶数值解 |
| 04 一纳米的差距 | 墙从 0.5 nm 增厚到 2 nm，透射概率从 2.4% 掉到 5×10⁻⁹ | 1 eV 电子、2 eV 势垒的精确定态解，加上对数坐标图 |
| 05 它一直都在 | 太阳核聚变、α 衰变、扫描隧道显微镜、闪存 | 四个小动画 |
| 尾声 | 「不可能」被划掉，换成「只是概率很小」 | |

第 4 部分的数字都按真实电子算：1 nm 时 T ≈ 1.4×10⁻⁴，2 nm 时 T ≈ 5.0×10⁻⁹，两者相差约 2.8 万倍。

## BGM

原创，全部由 `music.py` 用代码合成，不使用任何采样。

- F 大调，120 BPM，极简主义风格（类似 Steve Reich）：马林巴的 12 步音型叠在 8 步一小节上，重音会不断轮转错位
- 其他声部：拨弦贝斯、沙锤、柔和的合成器铺底、毛毡钢琴、FM 钟声
- 与画面同步：每次朱红划屏时有一声纸张掠过的音效；第 4 部分只剩滴答的钟声，制造紧张感；第 5 部分每出现一个应用就响一下钟声；「不可能」被划掉时有一记重音
- 响度 −16 LUFS
